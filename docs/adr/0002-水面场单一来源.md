# 水面场单一来源

- 日期：2026-10-19
- 状态：已采纳

## 背景

上一版是若干固定平面波叠加，另配一张与波场没有导数关系的噪声焦散图：波面出现平行条纹，沙底光网是一团团对不上水面的亮斑。曾打算把波场网格降一半当作纯性能优化，理由是谱已经截断、余量足够。

## 决定

斜率、拉普拉斯与焦散只从同一个随机波场的一次 FFT 里产出，谱也只在这一张固定尺寸的 k 格点上生成。

## 后果

波面朝向、沙底光网与镜面花纹天然对齐，不能再用第二个噪声场去「补」某个通道；单独更换焦散图案、或改采样方式与谱的归一化，都会同时改变这四处。网格尺寸也算在这个真源里：格点一变，每个 k 拿到的随机相位就全变，统计量看着差不多，但那已经是另一片海，不是重采样。

于是网格不能进「只删不可见的」的性能账，逐帧对照、曝光与薄膜的标定、各轮评审截图的可比性，全部只在同一网格下成立；要动它必须连带重做这三样。通道顺序与取样口径见 CONTRACTS.md。
