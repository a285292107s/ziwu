# 首帧主题预置走外链脚本

- 日期：2026-10-19
- 状态：已采纳

## 背景

主题的真源是异步的 chrome.storage.local，而第一帧不等它；MV3 生产环境的 CSP 只允许自身脚本，内联脚本被直接拦下，加 hash 又会被 Chromium 判为不安全的 CSP 值、整个扩展加载失败。内联与 hash 两条路都被否决，也没有接受「先按默认值画一帧、等异步回来再翻」。

## 决定

首帧要读的同步镜像写进 localStorage，由一段在 HTML 解析期间同步执行的外链经典脚本读回，并顺手放好深浅类与 color-scheme。

## 后果

这个脚本必须永远是经典脚本：一旦出现 import 或 export 就变成推迟执行的 module，首帧就晚了；index.html 里必须恰好一个对应标签，构建期要有守卫盯着镜像键与文件形态。镜像键、根上的两个类与 color-scheme 必须成对维护（见 CONTRACTS.md），跨文件常量只能放进一个不含任何 import 的模块，否则会牵连构建配置进程。

想回到内联、hash 或「等异步」，不是改一个值，而是换掉首帧主题的整条时间线。
