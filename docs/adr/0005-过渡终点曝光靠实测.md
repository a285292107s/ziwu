# 过渡终点曝光靠实测

- 日期：2026-10-19
- 状态：已采纳

## 背景

两片水的曝光差接近一个量级，终点没有解析式：介质、俯仰与窗的占比一起变，而增益还是有状态的。先用「该主题上次收敛的乘积」当终点，第一次切到某个主题时没有记忆可用；改成「一步反解再量一次」更糟：增益到显示亮度这条曲线在夜里很陡，一步从饱和端冲到过暗端、第二步再冲回来，固定两步等于把终点停在振荡的高侧，过渡结束整幅接近纯白。

## 决定

过渡开始的那一帧私下画几次终点帧、回读像素，在增益的对数上用割线法求根。

## 后果

每次切主题要多几趟低分辨率渲染与同步回读，是低频事件，不计入性能统计。这条路把「终点必须可测量」写成了前提：任何让终点帧无法私下渲染的改动——把探针挪到合成之后、让渲染器在过渡期间不可重入、或把回读改成异步——都会让机制失效，而不是变慢。

想改回解析式或记忆式，等于重做一层：这两片水之间没有那个公式，而记忆在第一次切换时必然缺席。
