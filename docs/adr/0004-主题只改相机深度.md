# 主题只改相机深度

- 日期：2026-10-19
- 状态：已采纳

## 背景

深浅两套主题需要差近一个量级的曝光。各调一套水参数最省事，但那样一来「浅色主题在夜里更亮」就成了一堆无法解释的数字，两套画面之间也不再是同一片水的两个位置，切换时无从插值。

## 决定

天文数据与水的吸收、散射常数两套主题共用，主题只决定相机停在哪个深度、有没有沙底；曝光差别是深度的物理结果。

## 后果

主题的身份被收敛成一个标量：深度。任何按主题单独调水常数的改动，都会同时破坏两套主题的曝光与色相校准，而且这种破坏不报错，只表现为画面偏亮或偏色。新增第三个主题也必须先回答「它停在哪个深度」，不能新增一组常数。

连带锁死的还有过渡：既然差异只在深度轴上，过渡就只能沿深度走，乘性量与辐射量按几何、离散量取目标帧（见 CONTRACTS.md），而终点曝光必须实测，不能靠记忆。
