# 品牌名定为子午 Ziwu

- 日期：2026-10-19
- 状态：已采纳

## 背景

发布前品牌名是「子午 Meridiem」。中文名与产品机制同源：天光按太阳时角计算，子午线就是时角为零的那条线。英文名 Meridiem 在英语里只指正午，与「子午」不对译；它与 Meridian 一字之差，而时间类产品里 Meridian 已经很拥挤：有同类的 Chrome 新标签页扩展、iOS 世界时钟，另有一个同样叫 Meridiem 的 iOS 世界时钟。对外发布后，英文名要承担识别与检索，继续沿用 Meridiem 等于把品牌放进别人的拼写纠错里。

## 决定

品牌名定为「子午 Ziwu」：中文名保留，英文名改为拼音 Ziwu，Meridiem 不再出现在用户可见的品牌位。技术标识冻结：storage 键前缀 `meridiem-`、备份格式 `meridiem.backup`、图标缓存键与 favicon 探测域名不随品牌改名；品牌名与技术标识解耦。

## 后果

用户可见处只能出现「子午 Ziwu」（或单独「子午」），不能再写 Meridiem。存量的 `mytab-*` 旧键迁移层保持原样；不要再为品牌改名迁移 storage 键或备份格式，否则会动到用户数据契约（见 CONTRACTS.md）。若将来再改英文名，先改品牌位与商店文案，不要碰这些技术标识。
