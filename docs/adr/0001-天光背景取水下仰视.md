# 天光背景取水下仰视

- 日期：2026-10-19
- 状态：已采纳

## 背景

新标签页要一块铺满整屏、又必须让文字读得出来的背景，同时希望一天里的变化落在色温而不只是亮度上。空气中天光的亮度几乎只由太阳高度决定，浅色主题在夜里要够亮就只能硬拉曝光，画面里也没有一块被光照亮的地面可以安放正文。备选是空气中的天光渐变，它最省钱、退化成 CSS 渐变也最容易。

## 决定

相机浸在海水里、向上看水面，天光的全部几何由水与空气的界面确定。

## 后果

介质一旦定在水下，相机、视场角、构图分区、曝光探针与可读性反馈就都长在这套坐标系上：窗、水体、沙底三段的分工、正文带的位置、吸收与散射的取舍，全部按水下推导。换回空气中的天空不是改一张贴图，而是重写着色器、重测探针、重定构图。

退到 CSS 渐变是唯一允许存在的第二套画面，它必须复现同一套时段语义，见 CONTRACTS.md。后来者不能在想要更亮或更有层次时改介质，只能在现有介质里调美术层。
